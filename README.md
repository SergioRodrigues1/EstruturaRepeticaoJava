# Curso Java - Professor Nélio

Este repositório contém alguns exercícios realizados durante o tópico **Estruturas Repetitivas** do curso de Java. Abaixo estão explicações sobre as estruturas de repetição `while`, `for` e `do`.

## Estruturas de Controle

### While

O `while` é uma estrutura de controle que repete um bloco de comandos enquanto uma condição for verdadeira. 
Quando usar: quando não se sabe previamente a quantidade de repetições que será realizada.

#### Sintaxe
```java
while (condição) {
    comando 1;
    comando 2;
}
```

### For

O `for` é uma estrutura de controle que repete um bloco de comandos para um certo intervalo de valores. 
Quando usar: quando se sabe previamente a quantidade de repetições ou o intervalo de valores.

#### Sintaxe
```java
for (início; condição; incremento) {
    comando 1;
    comando 2;
}
```

### Do

O `do` é menos utilizado, mas em alguns casos pode ser a melhor escolha. O bloco de comandos executa pelo menos uma vez, pois a condição é verificada no final.

#### Sintaxe
```java
do {
    comando 1;
    comando 2;
} while (condição);
```

---

Este repositório tem como objetivo ilustrar o uso dessas estruturas em diferentes cenários e como elas podem ser aplicadas de maneira eficiente.
